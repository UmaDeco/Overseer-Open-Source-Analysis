Event Choices

No event on screen. Open one in-game and every option's outcome appears here.
How exact is this?
The game sends every option's exact result before you click — these are outcomes, not odds. One card per button, in screen order. Some buttons carry several possible results, and the game rolls between them when it sends the event, not when you press: the card shows the result that will fire and the BRANCH n OF m tag says which one it is. Every event you answer is replayed against what actually changed on your trainee, and that score is the ✓ verified chip on the tab row — branch reads are scored there too, on a stricter test. Anything that fails lands in overseer-logs/event-outcomes.jsonl instead of passing silently. “Most stats” counts Speed/Stamina/Power/Guts/Wit + skill points only — energy, mood, bonds and hints are often the better reason to take the other option.

Training

No career turn on screen. Open the training screen in-game and every facility's exact gains, energy cost, fail rate and hint appear here.
How to read this table
One row per facility, built from the numbers the game sent for this turn. The stat columns are exactly what you gain if the training lands, Energy is what it costs (or gives back), and Fail is the game's own failure chance — that roll happens when you click, so the percentage is the whole story anyone can know in advance. The [!] Hint column is already decided: that facility will hand you a hint from the named card, and the list under it is that card's entire pool — the game never names the skill beforehand, so treat it as a shortlist, not a prediction (across a full career the skill that landed was in the offering card's pool 11 times out of 11). Dimmed entries are hints you already hold.

Race Field

No race loaded. Open a race's entry screen in-game and the whole field appears here.
Where these numbers come from
Every runner's exact stats, aptitudes and mood, as the server sends them at the entry screen — a few seconds before you commit, and before the forecast below exists. Ranked by raw stat total; the aptitude columns are for this race's surface, distance and each runner's own style.

Race Forecast

No race loaded. Enter a race in-game and the forecast appears here.
Why this is empty at the entry screen
Decoded from the game's own pre-computed race data the moment the race loads — so you know the result before watching it, but not while still deciding whether to enter: the server hasn't run the race yet at the entry screen. This panel is cleared when you enter a race and stays empty until the real result arrives, so it can never show you the previous race's finish. Retrying a race rolls a new outcome.

SuperSkip · client-side mod

Speed tip: skipping advances with every rendered frame, so heavier graphics settings (high anti-aliasing, long shadow distance, forced max model quality) can make Super Skip noticeably slower. Default graphics — or Low Resource Mode on the Performance page — skip fastest.

Auto-skip

Event choice → top option works now. Confirm warnings and Inspiration are being finalized — turn them on and trigger one of each so the bot can identify those exact buttons safely.

Race Fast-Forward

Automatically engages the game's own in-race Fast-Forward (accelerated playback) as each race begins. Unlike Skip, Fast-Forward works on races you can't skip yet (a grade's first win, forced-watch races) — so you never sit through one at normal speed. Complements Hyper Skip (which jumps won races straight to the result).

Hyper Skip · experimental

Auto-clicks the in-race Skip button the moment it appears (instant races) and auto-advances "tap to continue" prompts — no input needed. Career only. Only presses buttons you could press yourself; it won't touch confirmations or spend resources.

UI Speed

Animation speed 1×
1–10× is comfortable. 10×–20× is experimental: only the UI is accelerated, so the game's real-time work can lag behind it.
Why a fast skip costs frame rate
Animations are sub-stepped, so high speeds no longer overshoot or flash — the old 5× ceiling is gone. Above 10× the game's real-time work (asset loads, network) can lag behind and leave you waiting on a loading screen. The idle main menu always runs at 1× so its looping decorations don't strobe.

Expect the frame rate to dip while a fast skip is running — that is the animation pump doing the work, and the higher the speed you ask for, the more of each frame it is allowed to spend (a 144 fps floor at low speeds, sliding to 60 fps at 20×). The Performance page shows the live frame time and the pump's share of it.

Performance · client-side mod

Low Resource Mode

For weak PCs, and the fastest option for Super Skip. Overrides the graphics enhancements below.
How far to push
Balanced — no anti-aliasing, no per-pixel lights, short shadow distance, no LOD cross-fade.
Aggressive — the above, plus shadows off entirely.
Extreme — the above, plus the frame rate capped to 60. An uncapped game renders as fast as the hardware allows and burns the whole GPU doing it, so on a machine that is struggling this is the largest single saving available. Your own FPS cap is remembered and handed back when you leave this tier.
These tiers are deliberately short. This build of the game has most of Unity's quality settings stripped out by IL2CPP — anti-aliasing, per-pixel lights, shadow distance and LOD cross-fade are the only ones that exist, confirmed by reading the values back out of the engine. Options that would silently do nothing are not offered here.

Shadows
Shadow distance default
Shadow distance is the real perf lever: lower = fewer objects cast shadows = cheaper. Setting shadows Off forces distance 0 and overrides the slider.
How these apply, and what isn't offered
These write Unity's QualitySettings live and are re-asserted every 2s, so they apply immediately — no scene reload, and the game's own quality pass can't stomp them.

The grey text after a row is what the engine reports back — proof the write landed, not just that it was stored. Anti-aliasing has it; shadow distance says no readback because Unity stripped that getter from this build (the setter still works — you'll see it in-game).

Default restores the game's own value, captured before the first override — for anti-aliasing that's exact and instant. Shadow distance can't be read, so there's no original to put back: Default just stops overriding, and the last value stays until you restart the game.

Anisotropic filtering, texture quality, LOD bias, shadow resolution, render scale and HDR are not offered. Two hard limits, both verified against this build: Unity stripped those QualitySettings APIs out of the binary (the game never calls them, so IL2CPP removed them), and the game renders on the built-in pipeline — every render-pipeline getter returns null, so the URP asset those knobs would drive is never used. Any switch for them would be dead.

Ray tracing (RTX/DLSS): the engine has no RT pipeline, so it can't be enabled in-game. For a ray-traced look — screen-space GI, ambient occlusion, reflections — use ReShade injected over the game. Ask me and I'll set it up.

Help · passive observer & QoL mod


        

          
Getting started

          
What Overseer is
An in-game overlay plus this web control panel. Overseer watches the game and helps out — it never plays for you. It's passive and read-only by default.

          
The control panel
This page is the main control surface. It runs at 127.0.0.1:1620 in your browser while the game is open.

          
In-game overlay
The in-game overlay is now just an optional FPS counter (toggle it under Performance). Every control lives here in the web panel.

        


        

          
Features

          
Dashboard
Career and run tracking — live stats for the run in progress, plus a leaderboard and history of finished careers.

          
Live Advisor
A local engine that suggests training and event choices while you're on a career screen. Advice only — you stay in control.

          
Translation
Live machine translation of the game's text, plus support for community localized_data/ packs.

          
SuperSkip
Quality-of-life skipping and speed-up of race, event and training animations.

          
Performance
Unlock the frame rate, adjust graphics quality, and change display and window options.

          
Veterans
Your roster of trained umas, read from the game's own records.

          
Accessibility
Colour-blind-safe palettes, reduced motion, high contrast and larger text.

Common problems

          
The game won't launch
Overseer installs as a proxy DLL (cri_mana_vpx.dll) in the game's Plugins\x86_64 folder. If the game won't start: close any other mod or tool that injects into the game before launching, verify the install path, and if needed restore cri_mana_vpx_orig.dll over cri_mana_vpx.dll.

          
The web panel won't load
The game has to be running. Overseer serves this page at 127.0.0.1:1620 only while the game is open.

          
Antivirus flags the mod
Some antivirus tools false-positive on the proxy DLL. Allow-list the game's install folder.

          
A translation looks wrong
Unsafe machine output is rejected automatically, and community packs override it. You can also correct any single line under Translation → Fix a translation.
